# Scripts

This folder contains utility scripts used to support development, testing, data processing, and maintenance for the Queen's Vertical Farming Team Stack project.

## Purpose

Scripts in this folder may be used for:

- Testing sensor data
- Generating sample telemetry
- Importing or exporting data
- Database maintenance
- Development setup
- API testing
- Data cleaning
- Debugging devices
- Automating repetitive development tasks

## Guidelines

Scripts should:

- Have a clear purpose
- Include comments explaining what they do
- Avoid hard-coded passwords, API keys, or credentials
- Be safe to run in a development environment
- Include usage instructions when necessary

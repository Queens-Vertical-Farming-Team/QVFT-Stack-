# Documentation

This folder contains technical documentation for the Queen's Vertical Farming Team Stack project.

The goal of this documentation is to make the system understandable, maintainable, and accessible to future QVFT members and external contributors.

## Documentation Structure

Planned documentation includes:

- `architecture.md` — overall system architecture
- `onboarding.md` — setup guide for new Stack Team members
- `sensors.md` — sensors, devices, and hardware interfaces
- `api.md` — backend API documentation
- `database.md` — database structure and schema notes
- `deployment.md` — deployment and hosting information
- `troubleshooting.md` — common issues and debugging guidance

## Documentation Goals

The documentation should explain:

- how the different parts of the Stack system communicate
- how to run each component locally
- how devices send data
- how data is stored and retrieved
- how the dashboard works
- how contributors should test and submit changes

## Open Source

QVFT aims to make its technical work accessible so that students, researchers, and other teams can learn from and build on the project.

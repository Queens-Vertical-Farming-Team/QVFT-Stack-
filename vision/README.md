# Plant Vision

This directory contains software and documentation for QVFT camera-based plant monitoring.

Planned areas include:

- scheduled image capture
- camera configuration
- NIR / multispectral imaging
- true NDVI or other vegetation indices where supported by hardware
- canopy coverage
- growth tracking
- plant segmentation
- future stress and disease analysis

## Important

A standard RGB camera alone does not produce true NDVI. True NDVI requires red and near-infrared measurements.

Keep raw data or large image datasets outside Git unless a small public sample is intentionally included.
